# Desenvolvimento Web – Semana 02

Estilização com CSS do formulário de inscrição do blog, usando Flexbox.

## Arquivo

- `atv 2 web.html` (CSS embutido em `<style>`)

## O que foi aplicado

- Container do formulário com largura máxima, padding e fundo diferente do fundo da página
- `display: flex`, `flex-direction: column` e `gap` para organizar os campos
- `padding`, `border`, `border-radius` e `font-size` em `label`, `input` e `select`
- Botão com `background-color`, `color`, `padding`, `cursor: pointer` e `button:hover`
- Bônus: nome e e-mail lado a lado com `display: flex` e `justify-content: space-between`
